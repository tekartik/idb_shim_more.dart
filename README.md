# idb_shim_more.dart

More packages and experiments around
[idb_shim](https://pub.dev/packages/idb_shim), as git dependencies (none is
on pub.dev):

* [idb_shim_html_compat](packages/idb_shim_html_compat): legacy browser
  factory built on `dart:html` (dart2js only), for apps not yet on
  `package:web`.
* [tekartik_sdb_sembast](packages/sdb_sembast) (`packages/sdb_sembast`): the
  sdb API on top of sembast, without IndexedDB (experimental).
* [tekartik_idb_provider](packages/idb_provider) (`packages/idb_provider`):
  provider pattern and typed records on top of idb_shim (not maintained).

The other packages are playgrounds and experiments.
